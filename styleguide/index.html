Design system

Style guide

Every token and component the site is built from. Use the cup and cocktail switch in the header, or add ?theme=day or ?theme=night to the address, to see either theme.

The rule: a value that more than one thing shares is a token in site/data/tokens.json (colour, type, space, radius, border, shadow, motion, layers, tap targets, measures, breakpoints). The geometry of one component (a thumbnail width, a column count, a tilt) stays in the stylesheet next to that component. A test enforces both halves.

components/moments-grid

moments-grid: moments (list of moment views), t, count (optional: show only the first so many). Columns that keep each photo's own shape. One grid is one lightbox group: previous and next stay inside it.

Select a photo: the lightbox opens it large in a native dialog built by site.js, night-coloured, with caption and date. Arrow keys and a swipe step inside one grid; Esc or the close button closes and focus returns to the photo. Without JavaScript the link opens the JPEG.

Layouts

LayoutWhat it is
layouts/basebase: the frame of every page: head (meta, link preview, favicons, theme script), header, main, footer, the one script. Every other layout fills its `content` block.
layouts/editoreditor: the frame of the editor at /edit/. The screens are drawn by edit/editor.js (src/editor/); it reads the site's files from edit/site.json. The editor speaks English and German and picks by the browser (src/editor/strings.ts); this frame is the same for both. noindex.
layouts/eventsevents: the events of the next 60 days, grouped by month, with the calendar link.
layouts/gallerygallery: every moment, albums first, each grid one lightbox group.
layouts/homehome: the sections named in home.yml, top to bottom.
layouts/notfoundnotfound: the 404 page. It is shown at any address, so it cannot know the visitor's language: every language gets its block, and site.js moves the right one to the top when the address says which.
layouts/pagepage: a plain text page from a Markdown file: title and prose.
layouts/styleguidestyleguide: this page. Tokens are listed straight from tokens.json, so a new token shows up by itself. Components and sections are listed from the template folders with the comment each file starts with; a new one needs its example added in the `case` below (a test fails while it is missing). This page is internal: English only, noindex.

sections/ticker

ticker: t. Two identical groups in one track that slides left by half its width, so the loop has no seam. The words are decoration (the address is in "Find us"), so they are hidden from screen readers. The whole ticker is one button without a visible mark: a tap, a click or Enter pauses the movement and starts it again (WCAG 2.2.2). It runs from the start on every device, also with "reduce motion" on (Harry's decision, 16 Nov 2026).
